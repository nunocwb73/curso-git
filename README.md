# Sistema Bancário em Java
 
Aplicação bancária desenvolvida em Java com o objetivo de praticar conceitos fundamentais de programação orientada a objetos e lógica de programação.
 
## Sobre o projeto
 
O sistema simula operações bancárias básicas, permitindo o gerenciamento de clientes e contas, além da realização de movimentações financeiras.
 
O projeto possui finalidade educacional.
 
## Funcionalidades
 
- Cadastro de clientes.

- Criação de contas bancárias.

- Consulta de contas cadastradas.

- Consulta de saldo.

- Depósito em conta.

- Saque.

- Transferência entre contas.
 
## Tecnologias utilizadas
 
- Java

- Programação Orientada a Objetos

- Collections Framework
 
## Estrutura do projeto
 
- `Cliente`: representa os clientes do banco.

- `Conta`: representa as contas bancárias e suas operações financeiras.

- `AplicacaoBanco`: controla a execução do sistema e a interação com o usuário.
 
## Como executar
 
1. Certifique-se de ter o JDK instalado.

2. Clone este repositório.

3. Abra o projeto em sua IDE de preferência.

4. Execute a classe `AplicacaoBanco`.

5. Utilize o menu interativo para realizar as operações bancárias.
 
## Objetivo educacional
 
Este projeto permite exercitar conceitos como:
 
- Classes e objetos.

- Atributos e métodos.

- Encapsulamento.

- Construtores.

- Relacionamento entre classes.

- Listas e coleções.

- Estruturas condicionais e de repetição.

- Modularização e organização de código.
 
---
 
**Observação:** Esta aplicação é exclusivamente educacional e não deve ser utilizada para operações financeiras reais.
